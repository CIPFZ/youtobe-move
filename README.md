# Youtobe-Move

YouTube 视频自动搬运到 Bilibili 的完整流水线系统。

## 项目目标

将 YouTube 上指定类型的热门视频，自动发现、下载并发布到 Bilibili 平台，实现端到端的视频搬运自动化。

## 业务架构

```
┌────────────────────────────┐       ┌──────────────────────────────┐
│   香港服务器                   │       │   本地电脑                      │
│   (youtobe-parser)           │       │   (social-auto-upload)         │
│                              │       │                                │
│  ① 定时发现 YouTube 热门视频  │ HTTP  │  ③ 定时拉取视频文件 + 元信息    │
│  ② 下载视频到服务器本地       │ ←──→ │  ④ 删除服务器端已拉取视频       │
│  ③ 提供 API 供本地拉取       │       │  ⑤ 调用 biliup 发布到 B 站      │
│                              │       │  ⑥ 本地追踪发布状态            │
└────────────────────────────┘       └──────────────────────────────┘
```

## 核心需求

### 香港服务器端

1. **视频发现**：通过 YouTube Data API v3，按分类关键词搜索热门视频
   - 分类：宠物(pets)、美女(beauty)、搞笑(funny)，可扩展
   - 按热度评分，每日选出 Top 5
   - 仅英文视频，有最低播放量/评论数/时长过滤

2. **视频下载**：通过 yt-dlp 下载视频文件 + 元信息 + 封面

3. **去重存储**：SQLite 记录所有已发现视频，video_id 唯一键去重

4. **滚动删除**：超过空间阈值（可配置）时，按时间顺序删除最旧视频

5. **对外 API**：暴露接口供本地拉取视频列表、文件、确认删除

6. **定时调度**：每日定时执行发现 + 下载流水线

### 本地电脑端

1. **定时拉取**：定时从香港服务器拉取待发布视频

2. **本地追踪**：SQLite 数据库记录完整生命周期
   - 拉取时间、发布状态、B 站链接、失败原因

3. **B 站发布**：通过 biliup 自动上传
   - 简介标注原 YouTube 链接
   - 自动映射分类到 B 站分区
   - 分时段发布，模拟正常行为

4. **发布策略**：每日 5 个视频分时段发布，失败不阻塞后续

## 项目结构

```
youtobe-move/
├── youtobe-parser/          # 香港服务器 — 视频发现与下载
│   ├── app/
│   │   ├── discovery/       # 发现模块（API搜索、评分、去重）
│   │   ├── downloader.py    # yt-dlp 下载模块
│   │   └── settings.py      # 配置管理
│   ├── daily_discovery.py   # 每日发现入口
│   └── main.py              # 流水线主入口
│
└── social-auto-upload/      # 本地 — 多平台自动上传
    ├── uploader/
    │   └── bilibili_uploader/  # B 站上传模块（基于 biliup）
    ├── sau_cli.py            # CLI 入口
    └── sau_backend.py        # Web 后端
```

## 数据流

```
YouTube API → 搜索 → 评分排序 → 去重(Top 5)
    │
    ▼
yt-dlp 下载视频 + 封面 + 元信息 → 服务器磁盘 + SQLite
    │
    ▼ (HTTP API)
本地定时拉取 → 下载文件 → 通知服务器删除 → 本地 SQLite 记录
    │
    ▼
生成标题/描述/标签 → biliup 分时段上传 → 更新发布状态
```
